# Guide d'utilisation - SlideStudio

## Présentation
SlideStudio permet de créer et gérer des présentations.

## Diaporama
- Appuyer sur F5 pour lancer la présentation.
- Utiliser la flèche droite pour avancer.
- Utiliser la flèche gauche pour reculer.
- Appuyer sur Échap pour quitter.

## Exportation
Les formats prévus sont PNG et PDF.

## Accessibilité
- Utiliser le clavier pour naviguer.
- Privilégier des couleurs contrastées.
- Afficher des messages clairs.
