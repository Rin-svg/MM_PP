Tests d’exportation – SlideStudio

1. Exportation PNG

* Vérifier qu’une diapositive peut être exportée en PNG.
* Vérifier que l’image générée est lisible.
* Vérifier que les dimensions de l’image sont correctes.
* Vérifier que les éléments de la diapositive sont visibles.
* Vérifier le comportement si le fichier existe déjà.

2. Exportation PDF

* Vérifier la génération d’un document PDF.
* Vérifier que chaque diapositive correspond à une page.
* Vérifier l’ordre des pages.
* Vérifier que les textes et les images sont correctement affichés.
* Vérifier le comportement en cas d’erreur d’exportation.

3. Gestion des erreurs

* Tester un chemin de destination invalide.
* Tester un dossier inaccessible.
* Vérifier les messages affichés en cas d’échec.

4. Validation

Les tests seront exécutés sur Windows lorsque l’exportation sera intégrée à l’application. Les résultats seront consignés après vérification.
