
# Charte graphique et accessibilité - SlideStudio

## 1. Objectif
Définir des règles visuelles pour rendre SlideStudio simple, moderne et accessible.

## 2. Couleurs
- Couleur principale : bleu.
- Arrière-plan : blanc ou gris clair.
- Texte : gris foncé ou noir.
- Boutons importants : couleur principale.
- Messages d'erreur : rouge.

## 3. Typographie
- Utiliser une police lisible.
- Garder une taille de texte cohérente.
- Mettre les titres en évidence.
- Éviter les textes trop petits.

## 4. Accessibilité
- Assurer un contraste minimum de 4,5:1 pour le texte normal.
- Permettre la navigation au clavier.
- Ajouter des indications claires aux boutons.
- Ne pas utiliser uniquement la couleur pour transmettre une information.

## 5. Cohérence
- Garder les mêmes couleurs dans toute l'application.
- Utiliser des icônes compréhensibles.
- Uniformiser les marges et les espacements.
- Afficher des messages d'erreur clairs.

## 6. Diaporama
- Affichage plein écran.
- Navigation avec les flèches directionnelles.
- Fermeture avec Échap.
- Interface simple et sans éléments inutiles pendant la présentation.
